# Desafio das Lâminas

Jogo de estudo para Patologia Geral Veterinária: identificar lâminas e peças, flashcards com repetição espaçada e perguntas de conceito.

Jogar: abra `index.html` (ou o link do GitHub Pages deste repositório).

Imagens da internet: Wikimedia Commons, licenças livres – ver `CREDITOS-IMAGENS-INTERNET.txt`.
Demais imagens: recortes do material de aula, usados apenas para estudo.
